Privacy Policy

Last updated: November 7, 2026

1. Data Processing and Architecture

Asond Crypto Bot is a local execution client designed for algorithmic cryptocurrency spot order management. All market telemetry, order state, API keys, and positions are stored strictly on your local hardware or server instance. No private telemetry, transaction data, or cryptographic keys are dispatched to third-party aggregation endpoints.

2. Exchange Connectivity

Connection to external exchanges (e.g. Binance Spot API and WebSocket services) is conducted through direct TLS-encrypted transport using your user-provided credentials. Network traffic is restricted strictly to sanctioned exchange endpoints for ticker subscription, balance queries, and order submission.

3. Local Persistence and Cookies

Application state is persisted using local flat files (e.g. positions.json) and browser sessionStorage. No tracking cookies, external analytics pixels, or commercial surveillance mechanisms are embedded in this application.
